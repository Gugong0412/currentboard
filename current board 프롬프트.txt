# 역할
당신은 정밀 계측 보드 설계 경험이 많은 하드웨어 엔지니어입니다.
아래 사양의 "DDI 소비전류 측정보드"에 대해 Phase 1(시스템 아키텍처 + 부품 선정 + 오차 예산)을 수행하세요.
회로도 상세 설계(넷 단위)는 Phase 2에서 하므로 이번에는 하지 않습니다.

# 규칙
- 부품 사양 수치(오프셋, 게인오차, 드롭아웃, 공통모드 범위 등)는 반드시 실제 데이터시트 값을 쓰고, 출처(품번 + 데이터시트 항목)를 명시하세요. 모르면 "확인 필요"로 표시하세요. 수치를 지어내지 마세요.
- 모든 부품은 Digikey/Mouser에서 현재 구매 가능한 양산 품번으로 선정하세요(EOL/NRND 금지).
- 각 설계 결정마다 "왜 이 선택인지"와 "대안 대비 트레이드오프"를 한두 줄로 쓰세요.
- 사양과 충돌하거나 불가능한 항목이 있으면 임의로 바꾸지 말고 "리스크/질문" 섹션에 적으세요.

# 1. 프로젝트 개요
- 측정 대상: 모바일 디스플레이 DDI(Display Driver IC)
- 목적: DDI 전원 레일별 평균 소비전류 측정 (120Hz, 1Hz 구동 조건)
- 파형 측정은 범위 외. 평균 전류만 정확히 측정하면 됨
- DDI 구동은 별도 AP 보드가 담당. 본 보드는 DDI에 전원 공급 + 전류 측정만 담당
- DUT 연결: 2.54mm 헤더핀 (전원 + GND + 제어신호)
- PC 연결: USB (통신 전용, Python UI에서 제어/로깅)
- 보드 제작: 회로도 작성 후 PCB 업체에서 제작 + 조립(PCBA). 수작업 납땜 고려 불필요
- 예산: PCB 제작 + 조립 + 부품 포함 약 100만원 (소량, 1~3장)

# 2. 전원 레일 사양

## 2-1. 보드에서 생성 + 전류 측정 (Remote sense로 션트 드롭 보상)
| 레일 | 전압 | active 전류 | blank 전류 |
|---|---|---|---|
| VDDI_DIG | 1.24V | 1~3mA | off (거의 0) |
| VDDI | 1.8V | 0.5~1.5mA | 200~500µA |
| VCI | 3.0V | ≤200µA | ≤200µA (동일) |
- 션트 저항 이후(DUT 쪽)에서 LDO 피드백을 받는 remote sense 구조로, DUT 인가 전압이 션트 드롭과 무관하게 유지되어야 함. 안정도(위상여유) 검토 포함.

## 2-2. 보드에서 생성, 전류 측정 불필요
| 레일 | 전압 | 최대 전류 |
|---|---|---|
| VDDIO1V2 | 1.2V | <20mA |
| 1.8V 공용 (1.8V_SYS + moscato VDDI_B + moscato 1.8V 전원) | 1.8V | 합계 <100mA (여유 포함해서 설계) |
| VBAT (moscato 입력) | 3.8V | 최대 1A |
- 1.8V_SYS, moscato용 1.8V 전원들은 하나의 레귤레이터 공유 가능. 단 VDDI(측정 레일)와는 분리.

## 2-3. 외부 PMIC "moscato" 생성 + 전류 측정 (보상 불필요, 션트 드롭 ≤100mV 허용)
| 레일 | 전압 | active | blank |
|---|---|---|---|
| AVDDH1 | 3~9V | ~1mA | ~1mA (동일) |
| AVDDH2 | 3~9V | 보통 5~10mA, 최대 20mA | 수백 µA |
| VGH | 5~10V | ≤1mA | 유사 |
| VGL | -3~-11V (음전압) | ≤1mA | 유사 |
- moscato는 사용자가 공급하는 PMIC(기밀, 데이터시트 제공 불가). footprint는 사용자가 제공하므로 보드에는 moscato용 영역/커넥션만 확보.
- moscato 요구사항: VBAT 3.8V(최대 1A), 1.8V 전원, EN 핀(1.8V GPIO, MCU 제어)
- 시점 기준 120Hz 1프레임 중 active ≈97%. 1Hz 구동 시 대부분이 blank 구간.

# 3. 측정 사양
- 측정 채널: 7채널 (VDDI_DIG, VDDI, VCI, AVDDH1, AVDDH2, VGH, VGL)
- 동시 측정 불필요(순차 가능). 단 각 채널 측정은 끊김 없는(gap-free) 연속 적분 평균이어야 함.
  → 1Hz처럼 짧은 펄스가 드문 파형에서도 평균이 정확해야 함. 측정 창은 10~30초 수준.
- 프레임 동기(TE) 사용 안 함
- 정확도 목표: 각 레일의 측정 대상 평균 전류(수십 µA 이상)에서 ±0.5% 이내 (교정 후)
- 기준(교정) 장비: Keysight 34465A
- 리더 제안 아키텍처 (검증 후 동의/반론 제시):
  - 채널별 단일 션트 + INA228 (20bit, ADC range ±163.84mV로 피크 여유 확보)
  - INA228 내부 charge accumulator를 이용한 gap-free 평균
  - 션트 초안: VDDI_DIG 10Ω / VDDI 20Ω / VCI 100Ω / AVDDH1 20Ω / AVDDH2 3Ω / VGH 20Ω / VGL 20Ω
  - 션트: 0.1% 이하, 저TCR(≤25ppm/°C, 가능하면 ≤10ppm), 4단자(Kelvin) 또는 Kelvin 레이아웃
  - VGL: INA228 GND를 VGL 노드에 플로팅 + 절연 DC-DC 전원 + I2C 디지털 아이솔레이터
  - 저전류 구간(특히 VDDI_DIG 1Hz 평균 약 8~24µA)이 가장 어려운 조건임
- 같은 INA228로 각 레일 전압(VBUS)도 함께 로깅

# 4. 제어/시스템
- MCU: STM32 계열 (USB FS 이상, USB CDC 가상 COM 권장). 품번은 최적 선정
- 보드 생성 레일의 모든 레귤레이터 EN을 MCU GPIO로 개별 제어 → 시퀀스/딜레이를 PC에서 설정 가능
- 파워온 시퀀스: Logic 레일 → Analog(moscato EN) 순. 파워오프는 역순
- DDI RESET 신호: MCU에서 출력 (1.8V 레벨, 레벨시프트 필요 여부 검토)
- moscato EN: 1.8V GPIO
- 전원 입력: DC 잭 5~12V 광범위 입력 (5V, 12V 어댑터 모두 사용 가능). VBAT 1A 포함 전체 전력 예산 산정
- USB는 통신 전용. PC–AP–DUT 간 그라운드 루프 방지를 위해 USB 절연(예: ADuM4160급) 적용 검토
- 교정값(채널별 gain/offset)은 MCU 플래시 또는 EEPROM에 저장

# 5. 요청 산출물 (이 순서와 제목 그대로)
1. 시스템 블록도 (텍스트/mermaid): 전원 입력 → 레귤레이터 → 션트 → 헤더, 측정 IC → I2C → MCU → USB 절연 → PC
2. 전원 트리 표: 레일 / 소스 / 레귤레이터 품번 / 입력전압 / 최대전류 / 손실(W) / 노이즈 고려사항
   - VBAT 1A 생성 방식(벅/LDO) 선택 근거와 발열 계산
3. 측정 채널 설계 표: 채널 / 션트값 / 최대 드롭 / 측정 IC 설정(ADC range, 변환시간, averaging) / 피크 여유(몇 배까지 포화 없음)
   - 리더 제안 션트값에 대한 동의 또는 수정안 + 근거
4. 오차 예산 (채널별, 최소/최대 전류 각각): 션트 공차, TCR, IC 오프셋, 오프셋 드리프트, 게인오차, 양자화/노이즈(평균 후), 교정 후 잔류오차 → 합산(RSS와 worst case 둘 다) 후 ±0.5% 충족 여부 판정
   - VDDI_DIG 1Hz 평균(8~24µA) 케이스 반드시 포함
5. VGL 음전압 측정 방식: 절연 플로팅 방식 vs 다른 방식(최소 1개) 비교 → 추천안과 구체 부품
6. Remote sense LDO 구조: 레일별 LDO 품번, 피드백 연결 방식, 안정도 리스크, 헤더/케이블 드롭 대응
7. MCU 선정 및 핀 할당 초안 (I2C 버스 구성 / INA228 주소 할당 / EN GPIO / RESET / USB / 디버그 SWD)
8. 교정 방식 제안: 34465A를 이용한 절차, 교정 포인트(레인지당 몇 점), 필요한 지그/정밀저항
9. BOM 초안: 품번 / 수량 / 단가(USD) / 구매처 / 비고 + 예상 부품비 합계, PCB(4층 가정)+조립 비용 추정 → 100만원 이내 여부
10. 리스크 및 질문 목록 (사양 충돌, 확인 필요 데이터시트 값, 리더 결정이 필요한 항목)
