결론: 아키텍처는 조건부 진행. 확정 결정은 재논의하지 않습니다. 이하 오차표는 검증 목표를 포함한 계산이며 ±0.5% 성능 보증은 아닙니다. 새로 확인한 핵심 제한은 TPS7A90의 ±1% 전압 정확도 시험이 5mA 이상이라는 점으로, 본 Logic 저부하 조건의 전압 정확도는 별도 확인이 필요합니다. [2]

1. 시스템 블록도 — 변경분

D1/D2/D5/D7 반영: 입력 12V → 보호 → AUX 5V 및 VBAT 3.8V 독립 벅. AUX·3.3V_CTRL은 default-on, DUT 6레일은 GPIO 제어. 전류 창에서 VBUS·온도 변환 금지, VBUS 핀은 전단. TE는 연결하지 않고 VDDI_DIG 전류만 동기원으로 사용합니다. 나머지 블록 연결은 변경 없음.

3. 측정 채널 설계 — 변경분

D3: 션트 순서 DIG/VDDI/VCI/AVDDH1/AVDDH2/VGH/VGL =20/20/100/20/3/20/20Ω 확정. AVDDH2 실장 후보 3.01Ω은 승인 명목3Ω에 대한 구매 후보로, 정확한 품번·허용편차 확인 후 실측 gain에 반영합니다. D1: ADCRANGE=0, MODE=Ah 고정. DIG는 540µs·AVG=1, 나머지는 4120µs·AVG=1로 바꿔 blank 판정 지연을 줄입니다. 설정은 창 도중 바꾸지 않습니다. 전압은 창 전후만 별도 취득하며 post-shunt 전압과 혼동하지 않습니다. [1]

내부 fractional 누적의 상세 반올림, 연속 5-byte 읽기의 일관성, 갱신과 읽기의 경합은 제조사 확인·실측 필요입니다. 위 끝점 모델은 내부 누적에서 매 변환마다 정수 전하를 잘라 버리지 않는다는 조건입니다. 저전류 DC 및 알려진 펄스 전하로 540µs/4120µs 설정을 비교해 시간축·누적 모델을 검증합니다. 내부 oscillator ±0.5%는 그대로 두지 않고 교정합니다. 전류 gain과 CHARGE 시간축 gain은 분리 기록합니다.

4.4 분압 tare의 온도 잔류

Rbottom=150kΩ, Vref=0.8V이면 B=5.333µA. 각 레일 Rtotal은232.5/337.5/562.5kΩ입니다. 고정전압에서 |ΔB|≈B×25ppm/°C×|ΔT|이므로 5°C:0.667nA, 10°C:1.333nA. 따라서 “nA 이하”는 ΔT≤7.5°C에서 성립하며, 모든 온도 범위에 일반화하지 않습니다. 두 저항 TCR은 저항값 가중 평균으로 계산하며 동일 부호25ppm 두 개를50ppm으로 더하지 않습니다.

5nA 목표는 B의937.5ppm. ΔT5°C의125ppm을 뺀 전압·기타 허용 여유는812.5ppm, 전압만으로 환산하면 DIG1.008mV /VDDI1.463mV /VCI2.438mV입니다. 출력이0.1% 변하면5.333nA가 생겨 TCR과 합쳐6.0nA로 목표를 넘습니다. 실제로 B=Vref/Rbottom이므로 reference 변화와 실제 후단전압 변화를 포함합니다. 5nA 할당 유지가 타당하지만 온도만으로 달성했다고 보지는 않습니다. 창 전후 VBUS는 전단전압이므로 후단=전단−Vsh 보정과 측정 오차가 필요하며, INA VBUS 정확도만으로 약1mV 검증을 단정할 수 없습니다.

5. VGL 음전압 측정 — 변경분

D4 승인 구조로 확정: RFM-0505S+TPS7A1633DGNR+ISO1641DWR, GND_F=VGL 소스측. 션트는 기존 방향 유지, 전류가 DUT에서 소스로 귀환할 때 양수로 정의합니다. 시스템 GND를 VBUS에 연결한 |Vsource|와 Vsh로 VDUT=−VBUS+Vsh를 복원합니다. 공급측 기준 VBUS 측정이며 창 전후만 읽습니다. 다른 구조의 비교는 종료합니다.

  1. 준비: DMM 교정 유효성·warm-up·ACAL·고정range·자동영점/NPLC 기록. 보드 열평형 후 레일을 실제 설정전압으로 켜고 DUT를 분리합니다. 분압·입력보호·절연통신은 정상 운용 상태로 둡니다.
  2. 영점: 30초 창을 반복하여 평균 및 CHARGE 영점률을 저장합니다. 전원을0V로 끈 영점은 사용하지 않습니다. 레일전압·온도·전원모드별 tare와 분산을 기록하고 전압 변경 후 다시 tare합니다. 후단 연결 누설이 실제 DUT 연결과 달라지는지도 검증합니다.
  3. Gain: 저항부하에 DMM을 직렬 연결하여 실제 Iref를 읽고, 같은 안정 DC 구간의 INA 평균에서 tare를 뺀 값으로 g=Iref/(Iraw−Izero)를 구합니다. 저항 명목값을 전류 표준으로 쓰지 않으므로 0.01% 저항은 불필요합니다. DMM burden으로 부하전류가 달라도 실제값을 사용하되 레일전압과 LDO headroom을 확인합니다.
  4. 시간축: 안정 DC에서 MCU의 교정된 시간 T와 CHARGE 증가량을 비교하여 kQ를 구합니다. Iref×T/(g·ΔQraw−교정된 zero 전하)를 사용하며 gain과 시간축을 이중 보정하지 않도록 계산 경로를 고정합니다. 시간기준 잔류0.02% 목표는 외부 기준 대비 MCU clock 검증을 포함합니다.
  5. 검증: 8/24µA는 계수 fit에서 제외. 저전류 DCI는 typical 정확도 한계를 함께 기록하고, 정량 판정이 필요하면 실제 측정한 저항과 DCV로 I=V/R을 구성합니다. 1Hz 동적 기준은 DMM으로 측정한 ON/OFF 정전류×독립적으로 확인한 pulse 시간비를 사용합니다. PC DMM 폴링을 gap-free 전하 기준으로 간주하지 않습니다.
  6. 종료: 지그와 DMM을 제거하고 운용전압 영점을 재검사. 20/25/30°C 또는 실제±5°C 조건에서5nA·gain 목표를 검증하고 계수·환경·CRC를 저장합니다.

최소 지그: 작은 PCB/범용기판+헤더/수동 점퍼, 채널별 1% 부하저항 조합, 저누설 MOSFET pulse load1개, Kelvin test pad와 DMM 케이블. 리레이 매트릭스·SMU·별도 정밀전압원은 기본 구매에서 제외합니다. 저항값은 V/I로 정하고 실제값은 DMM으로 측정합니다. 임시 견적은 기판·커넥터2~4만원+저항·MOSFET·소모품1~2만원=3~6만원입니다. 기존34465A와 시간검증 장비 보유를 가정하며 장비 구매·교정 의뢰비는 별도입니다. 저전류 검증용 저항은 온도 안정성을 확보해야 하지만 최초 공차를 극도로 좁힐 필요는 없습니다.

11. 측정 창 동기 알고리즘

11.1 검출 설정과 전하 누적 영향

1Hz 모드 DIG:540µs,AVG1,MODEAh. 약8ms pulse에 약15개의 변환이 들어갑니다. AVG64·4.12ms의263.68ms 표시 지연은 pulse edge 검출에 부적합합니다. 540µs는 offset 보증의 TCT>280µs 조건도 만족합니다. 짧은 변환으로 개별 잡음이 커지지만 4.1처럼 긴 창에서 평균합니다. pulse 높이×검출 폭으로 최종전하를 계산하지 않고 INA CHARGE를 계속 누적하므로 edge 양자화가 pulse 전하를 직접 잘라내지 않습니다. [1]

권고는 CNVR ALERT마다 timestamp를 기록하고 CURRENT+DIAG_ALRT를 읽어 새 표본과 flag를 확인하는 방식입니다. I2C400kHz에서24bit CURRENT≈54clocks=135µs,16bit DIAG≈45clocks=112.5µs, 합247.5µs+SW로540µs 안에 서비스하는 목표입니다. FIFO가 없으므로 지연 시 표본 overwrite 가능. 폴링 대안은250µs 주기 예약, 새변환 flag 확인 및 중복표본 제거; 지연·bus retry는 SAMPLE_GAP 처리합니다. CHARGE는 MCU 읽기 지연과 무관하게 계속 누적하나 동기 검출의 유효성은 별개입니다.

초기 threshold 예: tare 후 I_HIGH=100µA, I_LOW=50µA, HIGH2표본/LOW3표본 확인. baseline잡음·최소 pulse에 맞춰 고정하고 5~15ms 폭 범위는 초기 검증 가정일 뿐 사양이 아닙니다. falling 검출 뒤 guard=25ms를 초기값으로 두되 실제 LDO·INA filter·DUT decap 정착시간으로 확정합니다. 다른6채널은4.12ms·AVG1 CURRENT도 확인하여 snapshot 전후 blank plateau가 유효한지 확인합니다.

11.2 정수 프레임과 순차 읽기 시차

pulse0가 끝난 뒤 blank에서 Qstart, pulseN이 끝난 뒤 같은 위상의 blank에서 Qend를 얻습니다. 그 차에는 pulse1~pulseN, 정확히 N개가 들어갑니다. N=10~30으로 정하되 실제 T를 사용하고 N초라고 고정 나누지 않습니다. 시작/끝에 MODE 변경·RSTACC를 하지 않습니다. VBUS 사전 측정 뒤 shunt-only 정착+동기 획득을 완료하고 시작, 마지막 Qend 저장 후에만 VBUS 사후 측정으로 바꿉니다.

I2C charge40bit 읽기≈72clocks=180µs;7개 순차읽기1.26ms, 첫/마지막 중심시차1.08ms. SW·DIG 우선서비스를 포함해 2ms 이내를 설계 목표로 둡니다. 실측 시간을 기록하며 고정 순서·고정 일정으로 반복합니다. 7개가 동시에 latch되는 것으로 취급하지 않습니다.

모델끝점오차 식수치 예
공통T를 그대로 사용δI=Ib×(δend−δstart)/T차이2ms일 때 blank5.333µA(DIG분압):10s1.067nA=8µA의0.01333%;30s0.00444%
다른 채널 blank200µA같은식;평균200µA 예10s40nA=0.020%;30s13.33nA=0.00667%
고정순서 동일시차δend=δstart이면 정적skew는상쇄1.08ms 자체를 매번 오차로 더하지 않음
채널별 실제 시간Tjconstant Ib의전하와 tare는Tj로정규화constant blank는 소거; global 창과의차이는(Ib−Iavg)×Δδ/T로평가
ADC 갱신 age읽은Q는마지막 변환완료 시점 값그시점을모르면 age차≤tc. 4.12ms/10s=0.0412%×Ib/Iavg;30s0.01373%×비율

따라서 bus timestamp만으로0.02% 경계 목표를 보증할 수 없습니다. positive6의 ALERT 변환완료 timestamp를 이용하고 VGL은 DIAG 폴링으로 완료시점 구간을 기록합니다. read 중 갱신 경합이면 더 넓은 age bound 또는 재읽기로 처리합니다. blank에서 Q(tref)=Qread+Ib,raw×(tref−teffective)로 공통경계까지 보간하고, tare도 동일 시간축으로 제거합니다. 변환 filter 유효지연은 알려진 step 시험으로 보정합니다. Ib 추정오차×age 불확실도까지 산출해 허용량을 넘으면 WINDOW_UNCERTAIN. 일관된40bit snapshot이 확인되지 않으면 그 창은 수치가 그럴듯해도 무효입니다.

분압이 흐르므로 DIG DDI 전류≈0이어도 raw Ib는0이 아닙니다. 원시 CHARGE를 먼저 경계 보정하고 동작전압 tare 전하를 빼야 합니다. 다른 채널의 blank를 DIG처럼0으로 가정하면 안 됩니다. 끝점 전압 변화의 축적전하 오차는 CΔV/T. 예:100µF·10mV/10s=0.1µA=8µA의1.25%. 0.02% 전부를 이 항에 할당해도 DIG8µA에서 ΔV≤0.16mV(10s),0.48mV(30s)가 필요하므로 충분한 정착·반복성 또는 별도 보정이 필요합니다.

11.3 120Hz: 동기 없이 충분한가

안정 반복·비음수 전류의 임의 위상창에서 프레임전하 1개 이하 경계오차를 쓰면 상대오차≤1/(fT).120Hz에서는10s0.08333%,30s0.02778%. DIG 직사각형 duty≈0.97,blank≈0의 더 강한 가정을 쓰면 ≤(1−d)/(fT):10s0.00250%,30s0.000833%. 후자는 실제 파형 확인 전 다른 채널에 적용하지 않습니다. 주파수 변화·비주기 업데이트·역전류가 있으면 일반 bound부터 재평가합니다.

120Hz는 30초 비동기 창을 기본으로 권고합니다. 일반 프레임위상0.02778%만으로 4장 동적할당0.02%를 초과하므로 표의 합계에 최소0.00778%를 더하고, ADC age·decap 등 잔여분을 별도로 더해야 합니다.10초는 최소0.06333% 추가입니다. 실제 DIG duty bound와 변환경계 보정으로0.02% 안에 드는 것이 확인되면4장 표를 그대로 사용할 수 있습니다. 평균창 길이만으로 모든채널의±0.5%를 자동 보장하지는 않습니다.120Hz에서는 필요시DIG도4120µs로 고정 전환하고 새 noise/age 예산을 적용합니다; 창 도중 전환 금지.

11.4 펌웨어 의사코드와 유효성 플래그

configure_1Hz():
    measure_VBUS_and_temperature_before_window()
    set_all(MODE=0xA, ADCRANGE=0, SHUNT_CAL=4096)
    set_DIG(VSHCT=540us, AVG=1, CNVR_ALERT=enabled)
    set_other_channels(VSHCT=4120us, AVG=1)
    load_calibration_for_operating_voltage_and_temperature()
    wait_filter_and_power_settled()
    state = ACQUIRE_SYNC; previous_result.stale = true

on_DIG_conversion(timestamp):
    raw, diag = read_CURRENT_and_DIAG_before_next_conversion()
    if missing_sample_or_fault: invalidate(SAMPLE_GAP); reacquire()
    edge = hysteresis_and_debounce(raw - operating_tare)
    if edge == RISE: remember_rise_timestamp()
    if edge == FALL and pulse_width_is_plausible:
        verify_period_and_increment_observed_pulse_count()
        schedule_blank_boundary(fall_timestamp + verified_guard)

at_blank_boundary(tref):
    if not all_channel_plateaus_valid(): invalidate(NOT_BLANK); return
    # fixed order, DIG conversion service has priority; no RSTACC here
    for channel in seven_channels:
        Qraw, t_read, t_effective_interval, flags = coherent_charge_read(channel)
        if flags: invalidate(flags); return
        # convert raw counts to coulombs before adding blank current x time
        Qref[channel], uncertainty[channel] = extrapolate_in_flat_blank(
            Qraw, calibrated_raw_blank_current, t_effective_interval, tref)
    if boundary_uncertainty_exceeds_budget(): invalidate(WINDOW_UNCERTAIN); return
    if state == ACQUIRE_SYNC and enough_valid_periods():
        start = {Qref, tref, pulse_count}; state = IN_WINDOW
    elif state == IN_WINDOW and pulse_count - start.pulse_count == N:
        T = tref - start.tref
        for channel:
            deltaQ = signed40_modular_difference(Qref[channel], start.Qref[channel])
            Iavg[channel] = calibrated_charge(deltaQ, T) / T - operating_tare[channel]
        if valid_voltage_temperature_and_all_checks(): publish(Iavg, T, N, VALID)
        else: publish_invalid_with_reason()
        measure_VBUS_and_temperature_after_window()
        start_next_acquisition()  # includes shunt-only settling again

on_timeout_or_fault():
    # e.g. >1.5 x learned frame period: initial tolerance, validate for actual panel
    invalidate(NO_PULSE_OR_DETECTION_FAILURE)
    retain_previous_value_with(stale=true, valid=false, age=elapsed)
    # Never infer missing pulses, never publish zero or normalize by requested N seconds.
    reacquire_full_window()

필수 flags: VALID, STALE, NO_PULSE_OR_DETECTION_FAILURE, SAMPLE_GAP, PERIOD_OUT_OF_RANGE, NOT_BLANK, WINDOW_UNCERTAIN, ADC_OVERFLOW, BUS_ERROR, CAL_OUT_OF_RANGE, RAIL_CHANGED. pulse 미검출은 “프레임 미갱신”과 “검출 실패”를 전류만으로 확실히 구별할 수 없으므로 공통 원인 미정 flag로 냅니다. 이전 수치는 표시하되 회색/시간경과/무효 상태를 함께 표시하고 새 정상값처럼 갱신하지 않습니다. 별도 요청이 있으면 실제 시간창 평균은 UNSYNCED 진단값으로만 기록할 수 있습니다. 부호확장·40bit rollover·overflow flag와 시간축 계수는 단위시험 및 알려진 전하 시험으로 검증합니다.
