01 · 이 블록의 기능과 경계

USB-C 데이터와 PC 접지를 보드의 측정 GND에서 분리하는 블록입니다. USB 전력 전체를 보드로 공급하는 구조가 아니며, ADuM4160의 양측 전원은 각각 host VBUS와 CTRL_3V3입니다.

02 · 부품과 실제 넷을 합친 통합 연결도

부품의 핀 번호에서 중앙의 넷 이름으로 이어지는 선이 실제 연결입니다. 같은 넷 상자로 모인 핀은 전기적으로 연결됩니다. 선의 교차 자체는 접속이 아니며 좌우 배치는 전류 방향이 아닙니다. 주황 점선은 션트의 같은 단자 동박 연결, DNP 가지는 기본 미실장입니다.

‘통합 전체’에는 이 블록의 모든 전기 부품이 들어갑니다. 복잡한 블록은 같은 회로의 하위 범위를 골라 읽을 수 있습니다. 넷 상자를 누르면 연결선과 외부 블록의 핀 목록이 함께 강조됩니다.

넷 이름을 클릭해 전원·접지·신호의 연결을 따라가세요.

ERC 가상 선언: #FLG1200 → USB_VBUS, #FLG1201 → USB_GND. 전원 생성 부품이 아닙니다.

03 · 값의 근거와 동작 해설

연결 사실은 네이티브 넷리스트, 정격 조건은 출처, 계산은 본문의 가정에 근거합니다. 기록이 없는 선정 의도는 회로에서 추정한 설명입니다.

커넥터와 CC 저항

J1200은 USB4105-GF-A이고 A6/B6은 D+, A7/B7은 D−로 각각 합쳐집니다. CC1과CC2는 서로 합치지 않고 R1200/R1201=5.1kΩ으로 USB_GND에 각각 내립니다. 뒤집어 꽂는 방향별 sink 인식을 위한 Rd 구성입니다. SBU A8/B8은 NC이며 PD 협상 회로는 없습니다.

R1206=0Ω은 실드를 host측 USB_GND에 잇습니다. 네 shield stake는 하나의 S1 번호로 처리한 이전 수정본을 그대로 사용합니다. USB_GND를 GND/GND_F에 연결하는 부품은 이 회로에 없습니다. GCT USB4105 제품 사양 — 로컬 history/R2_FIX_003/usb4105.pdf 제조사 도면과 기존 수정 기록 사용; 온라인 사양 직접 확보 실패

ADuM4160 양측 전원과 모드

측1: VBUS1=USB_VBUS(5V), VDD1=USB_3V3_LOCAL은 내부 레귤레이터 쪽이며 C1201로 바이패스합니다. PDEN/SPU는 이 로컬3.3V에 연결됩니다. 측2: VBUS2와 VDD2를 모두 CTRL_3V3에 연결하고 SPD도 High입니다. 양측 full-speed 설정입니다. Analog Devices ADuM4160 · Rev E — p.8~9 핀 기능, p.11~12 전원 연결과 full-speed 응용

C1200/C1205는 host VBUS에100nF+1µF, C1201은 로컬 LDO에100nF입니다. C1202/C1203은 측2 각 전원 핀 근처100nF, C1204는1µF입니다. host VBUS 직접 명목용량은1.1µF이며 이것만으로 전체 USB compliance를 판정하지 않습니다.

24Ω 직렬값과 attach

R1202/R1203은 host D±, R1204/R1205는 MCU쪽 D±에 들어갑니다. ADuM full-speed 응용의 직렬 종단값24Ω를 따른 구성입니다. 두 데이터 선의 균형과 IC 가까운 위치가 중요하며 DC 전압 분배용 저항이 아닙니다.

초기 detach → USB 준비 후 MCU가 attach 허용

ESD가 흐르는 경로

U1201은 D+/D−→USB_GND, U1202/U1203은 각 CC→USB_GND, U1204는 VBUS→USB_GND에 붙습니다. 데이터 선에 전원을 공급하거나 USB PD 과전압을 지속 차단하는 부품은 아닙니다. 커넥터에 가깝고 host측 귀환 루프가 짧아야 합니다. TI TPD2EUSB30 — DRT 핀, 양 채널 USB ESD 배치 TI TPD1E10B06 — DPY 두 단자, ESD 동작과 정격

절연은 신호 경로뿐 아니라 실드·mounting·계측기 접지까지 함께 유지해야 합니다. USB 절연 정격과 전체 시스템 안전 인증은 별개입니다.
