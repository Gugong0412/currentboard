01 · 이 블록의 기능과 경계

AUX_5V에서 CTRL_3V3를 만드는 제어용 LDO입니다. MCU, INA228의 양전압 측 전원, USB 절연기 보드 측과 여러 LDO의 입력을 공급합니다. U400.EN=AUX_5V로 먼저 켜지는 구조입니다.

실제 연결을 따라 읽는 순서

  1. AUX_5V가 U400 IN과 입력 MLCC에 도달하고 EN도 같은 AUX_5V를 받습니다.
  2. U400 OUT의 CTRL_3V3는 출력 C403·C404로 안정화되며 MCU와 제어 회로로 공급됩니다.
  3. R400+R401 / R402의 분압을 FB가 읽어 3.3V로 조정합니다.
  4. SS_CTRL=GND와 C405의 조합이 NR/SS 기동을 결정합니다. C406은 기본 미실장입니다.
  5. PG_CTRL_3V3의 풀업 전원도 CTRL_3V3입니다. 이 전원이 없을 때 PG에 외부 High가 생기지 않습니다.

02 · 부품과 실제 넷을 합친 통합 연결도

B1과 같은 회로 기호로 IC와 주변 R·C·L, 제어·피드백 경로를 함께 배치했습니다. ●는 접속점이며 선의 교차만으로는 연결되지 않습니다. 같은 넷 이름은 전기적으로 연결됩니다. 주황 점선 소자는 DNP, 션트의 금색 선은 같은 물리 단자의 동박 연결입니다. 핀 위치는 읽기 위한 기능 배치로 실제 패키지 방향이 아닙니다.

‘통합 전체’에는 이 블록의 모든 전기 부품이 들어갑니다. 복잡한 블록은 같은 회로의 하위 범위를 골라 읽을 수 있습니다. 넷 이름이나 배선을 누르면 같은 넷의 연결선과 외부 블록 핀 목록을 확인할 수 있습니다.

03 · 값의 근거와 동작 해설

연결 사실은 네이티브 넷리스트, 정격 조건은 출처, 계산은 본문의 가정에 근거합니다. 기록이 없는 선정 의도는 회로에서 추정한 설명입니다.

피드백 저항으로 정하는 전압

TPS7A90의 기준 0.8V를 이용합니다. 아래는 실제 저항을 대입한 명목값이며 기준전압·저항·온도 오차를 제외했습니다. TI TPS7A90 · SBVS324B — p.3 핀, p.6~7 특성, §6.3.6 기동, §7.1.3 커패시터

입출력 커패시터와 100nF NR/SS

입력 커패시터는 상위 전원까지의 배선 인덕턴스 때문에 생기는 순간 전압 강하를 보완합니다. 출력의 22µF 두 개는 OUT에 직접 연결된 로컬 안정화 용량입니다. 일반 100nF 바이패스와 NR/SS의 100nF는 같은 값이어도 역할이 다릅니다.

SS_CTRL=GND에서 NR/SS의 대표 충전 전류 6.2µA를 쓰면 100nF×0.8V/6.2µA≈12.9ms입니다. 4~9µA와 커패시터 ±10%만 반영한 단순 범위는 약 8~22ms이며, 완전한 안정화 보증 시간이 아닙니다.

B4는 입력 22µF 두 개와 출력 22µF 두 개를 두며 각각 유효 합 ≥10µF를 계약 목표로 삼았습니다. 실제 부품은 미선정입니다.

C406/C506/C526/C546/C606/C626 중 해당 블록의 100pF는 DNP 조정 자리입니다. 기본 회로에서 열린 가지로 그렸습니다. 무조건 장착하면 기동·피드백 루프가 바뀌므로 ‘노이즈용 커패시터니까 넣자’고 결정하지 않습니다.

LDO의 열과 enable

기본 열 근사: PD ≈ (VIN − VOUT) × IOUT
U400: (5−3.300)V × 0.1A = 0.170W (100mA 예시)

PG 풀업은 CTRL_3V3 기준입니다. U400은 AUX_5V가 올라오면 활성화되므로 MCU 없이 기동할 수 있습니다.

R·C를 하나씩 읽기: 연결 → 현재 값 → 바꾸면 달라지는 점

예: 명목 22µF 두 개 → 합계 44µF
실제 사용 전압·온도에서 각각 30%만 남는 가정 → 합계 13.2µF
이 30%는 특정 구매품의 보증값이 아니라 계산 예시
실구매 MPN의 DC bias 곡선 + 온도 + 공차를 합쳐 판단

직접 연결된 출력 C와 케이블 뒤 DUT C는 같은 루프 위치가 아닙니다. 데이터시트의 안정성 조건은 실제 부하·배선·용량 범위로 다시 확인해야 합니다. 현재 문서는 회로를 변경하거나 새 용량을 승인하지 않습니다.
