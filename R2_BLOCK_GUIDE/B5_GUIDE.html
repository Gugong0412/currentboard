01 · 이 블록의 기능과 경계

DIG·VDDI·VCI의 세 LDO와 션트 전후 피드백 선택 회로입니다. DIG·VCI는 DUT 후단 피드백입니다. VDDI는 R525 미실장·R526 실장으로 SRC 전단을 선택합니다. 006에서 Value 표시도 이 상태와 맞췄습니다. 이 세 회로는 B7 측정 IC와 함께 읽어야 합니다.

02 · 부품과 실제 넷을 합친 통합 연결도

부품의 핀 번호에서 중앙의 넷 이름으로 이어지는 선이 실제 연결입니다. 같은 넷 상자로 모인 핀은 전기적으로 연결됩니다. 선의 교차 자체는 접속이 아니며 좌우 배치는 전류 방향이 아닙니다. 주황 점선은 션트의 같은 단자 동박 연결, DNP 가지는 기본 미실장입니다.

‘통합 전체’에는 이 블록의 모든 전기 부품이 들어갑니다. 복잡한 블록은 같은 회로의 하위 범위를 골라 읽을 수 있습니다. 넷 상자를 누르면 연결선과 외부 블록의 핀 목록이 함께 강조됩니다.

03 · 값의 근거와 동작 해설

연결 사실은 네이티브 넷리스트, 정격 조건은 출처, 계산은 본문의 가정에 근거합니다. 기록이 없는 선정 의도는 회로에서 추정한 설명입니다.

피드백 저항으로 정하는 전압

TPS7A90의 기준 0.8V를 이용합니다. 아래는 실제 저항을 대입한 명목값이며 기준전압·저항·온도 오차를 제외했습니다. TI TPS7A90 · SBVS324B — p.3 핀, p.6~7 특성, §6.3.6 기동, §7.1.3 커패시터

VSET = 0.8 × (1 + RTOP/RBOTTOM)
IDIVIDER = VSET / (RTOP + RBOTTOM)

입출력 커패시터와 100nF NR/SS

입력 커패시터는 상위 전원까지의 배선 인덕턴스 때문에 생기는 순간 전압 강하를 보완합니다. 출력의 22µF 두 개는 OUT에 직접 연결된 로컬 안정화 용량입니다. 일반 100nF 바이패스와 NR/SS의 100nF는 같은 값이어도 역할이 다릅니다.

SS_CTRL=GND에서 NR/SS의 대표 충전 전류 6.2µA를 쓰면 100nF×0.8V/6.2µA≈12.9ms입니다. 4~9µA와 커패시터 ±10%만 반영한 단순 범위는 약 8~22ms이며, 완전한 안정화 보증 시간이 아닙니다.

현재 TI Rev B의 §7.1.3은 권장 명목 입력/출력 용량에 50% 디레이팅을 고려했다고 설명합니다. 따라서 B5/B6의 명목 10µF 입력을 곧바로 ‘유효 10µF 미달’ 오류로 단정하지 않습니다. 프로젝트 요구인 입력 유효 ≥5µF, 출력 유효 합 ≥10µF 및 실제 파형을 함께 확인해야 합니다.

C406/C506/C526/C546/C606/C626 중 해당 블록의 100pF는 DNP 조정 자리입니다. 기본 회로에서 열린 가지로 그렸습니다. 무조건 장착하면 기동·피드백 루프가 바뀌므로 ‘노이즈용 커패시터니까 넣자’고 결정하지 않습니다.

션트 전후 피드백의 전류·전압 해석

DIG의 R505, VCI의 R545는 FIT이고 전단 R506/R546은 DNP입니다. VDDI는 BOM상 R525(DUT)가 DNP, R526(SRC)이 FIT이므로 전단 피드백입니다. 전단·후단 점퍼를 동시에 실장하면 0Ω 경로가 션트를 우회하므로 둘 중 하나만 선택해야 합니다.

R525·R526 표기 수정 완료 (006): R525는 0R [DNP] / Population DNP, R526은 0R / Population FIT입니다. 실제 실장 플래그와 BOM은 원래 이 상태였으며 Value 표시 두 곳만 맞췄습니다. VDDI는 SRC 전단 피드백이므로 션트 전압 강하를 보상하지 않고, 분압 전류도 R527을 통과하지 않습니다. 기존 005 원본은 보존했습니다.
후단 피드백 DIG / VCI: VOUT_SRC ≈ VSET_DUT + ISHUNT × RSHUNT
DIG: 1mA × 20Ω = 20mV 보상 필요
VCI: 1mA × 100Ω = 100mV 보상 필요
분압 전류 = 0.8V / 150kΩ = 5.333µA
후단 구성에서는 ISHUNT에 피드백 분압 전류도 포함
전단 피드백 VDDI (BOM 기준): VDUT ≈ VSET_SRC − IDUT × 20Ω
VDDI 1mA 예: DUT는 명목 SRC보다 약20mV 낮음

따라서 후단 피드백 채널에서 5µA 수준의 DUT를 측정하려면 5.333µA의 명목 분압 소비를 포함한 영점·온도 보정을 고려해야 합니다. DIG의 펌웨어 SOVL raw100µA와 명목 DUT 약94.667µA 구분도 이 때문입니다. VDDI는 현재 BOM대로면 이 분압 전류를 션트에서 읽지 않습니다. 1mA는 계산 예시이며 운전값 승인이 아닙니다.

VDDI_SRC 1.8V는 VDDI·LPDP·OSC의 세 션트에 공통 공급됩니다. DIG 1.24V는 별도 U500 전원입니다. U520은 공통 SRC를 피드백하므로 세 분기의 각 DUT 전압 강하를 개별 보상하지 않습니다. 독립 전압 조정기 세 개로 해석하지 않습니다.

저항 전력과 고장 전류는 별도 검토

R507/R527은 1W 등급으로 보강된 기록이 있지만, 전류 제한 소자가 추가된 것은 아닙니다. 션트만 저항성 부하라고 놓아 3.3²/20≈0.545W를 계산할 수 있어도, 실제 고장에서는 LDO current limit·dropout·열 차단·동시 고장까지 달라집니다. INA 포화 상태의 값도 유효 측정으로 취급하면 안 됩니다.
