01 · 이 블록의 기능과 경계

U900은 MOSCATO_PLACEHOLDER이며 실제 확정 PMIC가 아닙니다. 이 블록은 다른 회로와 연결할 인터페이스 계약만 기록합니다.

실제 연결을 따라 읽는 순서

  1. B3 VBAT와 B6 SYS_1V8, B13 EN이 임시 U900 인터페이스로 들어갑니다.
  2. 출력으로 선언된 AVDDH1_SRC·AVDDH2_SRC·VGH_SRC·VGL_SRC가 각각 후단 션트들로 분기합니다.
  3. 이 연결 계약만으로 내부 전력 변환 방식·출력 정격·기동 순서를 결정할 수 없습니다.
  4. 실제 부품과 응용 회로를 받은 뒤 내부 회로·외부 R/L/C·핀 번호를 채우고 검증을 다시 해야 합니다.

02 · 부품과 실제 넷을 합친 통합 연결도

B1과 같은 회로 기호로 IC와 주변 R·C·L, 제어·피드백 경로를 함께 배치했습니다. ●는 접속점이며 선의 교차만으로는 연결되지 않습니다. 같은 넷 이름은 전기적으로 연결됩니다. 주황 점선 소자는 DNP, 션트의 금색 선은 같은 물리 단자의 동박 연결입니다. 핀 위치는 읽기 위한 기능 배치로 실제 패키지 방향이 아닙니다.

‘통합 전체’에는 이 블록의 모든 전기 부품이 들어갑니다. 복잡한 블록은 같은 회로의 하위 범위를 골라 읽을 수 있습니다. 넷 이름이나 배선을 누르면 같은 넷의 연결선과 외부 블록 핀 목록을 확인할 수 있습니다.

03 · 값의 근거와 동작 해설

연결 사실은 네이티브 넷리스트, 정격 조건은 출처, 계산은 본문의 가정에 근거합니다. 기록이 없는 선정 의도는 회로에서 추정한 설명입니다.

현재 연결이 뜻하는 것

VBAT는 B3의 3.8V, VDD1V8와 VDDI_B는 B6의 SYS_1V8, EN은 B13의 MOSCATO_EN_1V8입니다. AVDDH1_SRC·AVDDH2_SRC·VGH_SRC·VGL_SRC는 후단 측정 션트에 전달되는 공급원으로 선언되어 있습니다.

핀1~9는 프로젝트 임시번호입니다. 실제 부품의 package pinout으로 보지 않습니다. AVDDH2는 S/O와 GM, VGH는1·2, VGL은1·2로 분기합니다. 이름이 나뉘어도 이 블록에서 독립된 전압 조정기가 생성된 것은 아닙니다.

실제 MPN·데이터시트·외부 인덕터/저항/커패시터·제어 시퀀스가 없으므로 출력 전압, 정격 전류, 필수 부품의 선정 이유를 만들어 적지 않았습니다. 실제 회로로 대체한 뒤 넷리스트와 전체 전원 순서를 재검증해야 합니다.

B9에서 현재 계산할 수 없는 것

승압/반전용 인덕터 리플, 보상망, 최소부하, startup, discharge, 출력 오차·노이즈는 입력 자료가 없습니다. 아래 모든 핀 표는 연결 계약을 설명하며 전기적 적합성 승인이 아닙니다.

R·C를 하나씩 읽기: 연결 → 현재 값 → 바꾸면 달라지는 점

아래 계산은 회로의 선택 이유를 이해하기 위한 조건부 해설입니다. 기록에 없는 선정 의도를 사실로 단정하지 않습니다. 원 설계에서 MPN이 미확정이면 정격·온도·누설·DC 바이어스 검증도 미완료입니다.

이 블록에는 설정용 R·C가 없습니다. 없는 소자를 가정해 값 선정 설명을 만들지 않고, 아래 인터페이스·계측·기구 조건을 해설합니다.

06 · 1차 검토 결과와 남은 확인

  • 실제 부품 및 회로 제공이 B9 응용 해설 완료의 전제.
  • 펌웨어 DUT_SEQUENCE_APPROVED=false 상태 유지.
  • B9가 임시 상태이므로 전체 보드의 제작 HOLD 유지.

006 수정본은 R525·R526의 Value 표시만 BOM·실장 상태와 맞췄습니다. 기존 원본과 12채널 연결은 보존했습니다. KiCad 10.0.7로 새 넷리스트·ERC를 생성하여 8,437개 검사 통과, ERC 위반 0건을 확인했습니다. 실측 검증은 미완료입니다.
