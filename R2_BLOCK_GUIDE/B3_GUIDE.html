01 · 이 블록의 기능과 경계

보호된 12V를 3.8V VBAT로 낮추는 동기식 벅 전원입니다. U300의 SW에서 생긴 스위칭 파형을 L300과 출력 커패시터가 평균화합니다. VOS는 실제 출력점을, FB는 저항 분압을 봅니다. 부품 자체의 3A 표기가 B1의 약 1.49A 입력 제한을 없애지는 않습니다.

이름이 VBAT이지만 이 블록은 배터리 충전기가 아닙니다. MCU의 EN_VBAT으로 MOSCATO용 전원을 제어하고, R304가 MCU 초기 high-Z에서 OFF를 유지합니다.

02 · 부품과 실제 넷을 합친 통합 연결도

부품의 핀 번호에서 중앙의 넷 이름으로 이어지는 선이 실제 연결입니다. 같은 넷 상자로 모인 핀은 전기적으로 연결됩니다. 선의 교차 자체는 접속이 아니며 좌우 배치는 전류 방향이 아닙니다. 주황 점선은 션트의 같은 단자 동박 연결, DNP 가지는 기본 미실장입니다.

‘통합 전체’에는 이 블록의 모든 전기 부품이 들어갑니다. 복잡한 블록은 같은 회로의 하위 범위를 골라 읽을 수 있습니다. 넷 상자를 누르면 연결선과 외부 블록의 핀 목록이 함께 강조됩니다.

넷 이름을 클릭해 전원·접지·신호의 연결을 따라가세요.

ERC 가상 선언: #FLG0300 → VBAT. 전원 생성 부품이 아닙니다.

03 · 값의 근거와 동작 해설

연결 사실은 네이티브 넷리스트, 정격 조건은 출처, 계산은 본문의 가정에 근거합니다. 기록이 없는 선정 의도는 회로에서 추정한 설명입니다.

출력값을 두 개의 상단 저항으로 맞추기

R300과 R301은 직렬 상단 저항이며 중간점은 다른 부하에 연결되지 않습니다. 표준값 조합으로 목표 전압을 맞춘 것으로 해석됩니다. 하단 R302=100kΩ.

VOUT = 0.8 × (1 + RTOP / RBOTTOM)
RTOP = 374k + 1k = 375kΩ, RBOTTOM = 100kΩ
→ VOUT = 3.8V
분압 전류 = 0.8 / 100k = 8µA
R303 PG pull-up: 3.3V / 10kΩ ≈ 0.33mA (Low일 때)

FB 기준 0.8V, FSW=GND에서 대표 2.5MHz, DEF=GND에서 명목 출력입니다. PG는 3.3V로 풀업합니다. TI TPS62130A · SLVSAG7F — p.3 핀, p.5 전기 특성, p.14~17 출력·LC·SS 설정

2.2µH 인덕터와 입출력 커패시터

L300=2.2µH는 스위칭 한 주기마다 흐르는 전류 변화를 제한합니다. C300/C301=10µF 두 개는 펄스 입력 전류의 가까운 공급원이며 C302=100nF는 AVIN 근처 바이패스입니다. C303/C304=22µF 두 개는 출력 리플과 부하 변화를 받아 줍니다. 명목 합계 20µF/44µF와 DC 바이어스 후 유효용량은 구분합니다.

12V, 2.5MHz, 2.2µH를 가정한 CCM 근사
D ≈ VOUT/VIN = 0.317
ΔIL ≈ VOUT × (1 − VOUT/VIN) / (L × f) = 0.472A p-p
IL_PEAK ≈ ILOAD + 0.236A
LC 고유주파수(명목 44µF) ≈ 16.2kHz

경부하에서는 이 연속전도(CCM) 식 그대로의 파형이 아닙니다. Coilcraft의 2.2µH 행은 10% 인덕턴스 감소 기준 Isat 3.1A, DCR 최대 24mΩ를 제시합니다. 정격 전류 한 숫자보다 실제 피크·온도·포화 기준을 함께 봐야 합니다. Coilcraft XFL4020 · 2026-03-10 — 2.2µH 행의 DCR/Isat 조건; Isat와 Irms 구별

3.3nF 소프트스타트

C305=3.3nF
SS 기준 약 1.25V, 충전 대표전류 2.5µA
→ tSS ≈ 3.3nF × 1.25V / 2.5µA = 1.65ms

이는 레귤레이터의 명목 램프 추정입니다. 입력이 B1을 통해 올라오는 시간, 기동 부하, PG 판정 지연을 합친 보드 전체 준비 시간은 아닙니다.

R304와 R305는 서로 다른 OFF 역할

R304 100kΩ: EN의 기본 Low. 3.3V High에서 33µA
R305 1kΩ: 출력의 상시 방전 부하
3.8V / 1kΩ = 3.8mA; 3.8²/1kΩ = 14.44mW
C303+C304=44µF만 가정한 RC=44ms
3.8V→0.38V: RC×ln(10)≈101ms

R305는 출력 저장 전하를 줄이는 역할입니다. MOSCATO 입력 용량·외부 역급전이 있으면 위 방전 시간이 늘어나거나 아예 같은 지수함수로 내려가지 않습니다.
