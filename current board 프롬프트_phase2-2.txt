# Phase 2-2: MCU·USB·레벨시프터·DUT 헤더 + Phase 2-1 수정 + 전체 통합

## 배경
Phase 2-1(전원부+측정부) 설계표를 리더가 검토했고, 연결 계약 JSON을 자동 검증한 결과 연결 오류 0건이다.
이번 단계는 남은 디지털/인터페이스부를 설계하고, 2-1 수정사항을 반영한 뒤 보드 전체를 하나의 연결 계약으로 통합한다.
규칙·형식은 Phase 2-1과 동일하다 (KiCad 8.x, RefDes/넷 이름 규칙, 부품표/핀-넷 연결표, 모든 핀 기재, 데이터시트 근거, 미확인은 "확인 필요", 회로도 파일 직접 생성 금지).
Phase 2-1에서 정의한 RefDes·넷 이름·global label은 아래 수정 지시 외에는 변경하지 마라.

## Phase 2-1 수정 지시
F1. [OVP] U100 OVP 상승 임계를 약 15V로 상향 (어댑터 무부하 상승 대비, TPS62130A 입력 정격 이내). UVLO는 약 10V 유지. R100/R101/R102 E96 값 재계산 (예: 110k/4.99k/10k → OVP≈14.9V, UVLO≈9.9V 검증). 기준전압 공차 포함 최소/최대 차단점 제시.
F2. [CTRL_3V3 용량] B5/B6 하위 LDO 5개(U500/U520/U540/U600/U620)의 입력 커패시터를 각 10µF 1개(+필요시 100nF)로 축소. TPS7A90 입력 유효용량 요구조건을 데이터시트로 재확인하고, CTRL_3V3 총 용량과 U400 기동 시 돌입전류를 계산하라. 삭제되는 RefDes는 목록으로 명시.
F3. [ISO1641 핀맵] ISO1641DWR DW16 핀 번호/이름을 데이터시트 Pin Configuration 그림과 다시 대조하고, 대조 결과(일치/수정)를 표로 제시.

## 이번 설계 범위 (블록 번호 이어서)
B11. MCU: STM32F072CBT6 (LQFP48)
 - 전원 디커플링(VDD/VDDA), VDDA 필터, NRST(버튼+RC), BOOT0, SWD 헤더(Tag-Connect 또는 2x5 1.27mm 중 추천).
 - 시간축: 측정 창 시간 정확도가 오차 예산(교정 후 0.02%)에 들어가므로 HSE 크리스털 또는 TCXO 채택. 주파수·정밀도(ppm)·부하 C 계산 제시. USB는 HSE 기반으로 동작.
 - 핀 할당 전체 재작성 (Rev.A 핀 예시는 무시하고 AF 테이블 기준으로 새로 선정):
   · ALERT_VDDI_DIG_N → 타이머 입력캡처 채널 (양쪽 에지 캡처 가능 TIM/CH 명시, 32bit 타이머 우선 검토)
   · I2C1, I2C2 (AF 확인), USB DM/DP, SWD
   · EN 6개 (EN_VBAT, EN_VDDI_DIG, EN_VDDI, EN_VCI, EN_VDDIO1V2, EN_SYS_1V8)
   · PG 8개 + PWR_FLT_N 입력, 나머지 ALERT 5개 진단 입력 (핀 부족 시 우선순위와 TP 처리 방침)
   · 레벨시프터 제어 (MOSCATO_EN, DDI RESET)
   · 상태 LED 1~2개
 - 핀 할당표: 기능 / 포트 / LQFP48 물리 핀번호 / AF / 초기 상태 / 넷 이름
B12. USB 및 절연: USB-C(디바이스, CC 5.1k 풀다운) 또는 Micro-B 중 추천, ESD 보호, ADuM4160BRWZ 양측 전원(1측은 USB VBUS, 2측은 CTRL_3V3), 풀스피드 설정 핀, USB 실드 처리. USB VBUS는 보드 전원으로 쓰지 않는다.
B13. 레벨시프터: SN74AXC2T45DCTR (3.3V → 1.8V). VCCA=CTRL_3V3, VCCB=SYS_1V8. MOSCATO_EN_1V8와 DDI_RESET_N_1V8 출력. 
 - SYS_1V8이 꺼져 있을 때(EN_SYS_1V8=low) 출력 상태와 Ioff, 역급전 경로 분석.
 - MCU 리셋/부팅 중 MOSCATO_EN은 low, DDI RESET은 assert(low)로 유지되는 풀다운/풀업 정의.
B14. DUT 헤더 (2.54mm): DUT로 나가는 모든 전원과 신호의 핀맵.
 - 포함 넷: VDDI_DIG_DUT, VDDI_DUT, VCI_DUT, VDDIO1V2, SYS_1V8(1.8V_SYS), AVDDH1_DUT, AVDDH2_DUT, VGH_DUT, VGL_DUT, DDI_RESET_N_1V8, GND.
 - 각 전원 핀 옆에 GND 핀 배치(리턴 경로), 고전압(VGH/AVDDH)과 VGL은 인접 배치 피하기, 헤더 전류 정격 확인.
 - GND_F는 헤더로 내보내지 않는다 (VGL_DUT는 DUT 쪽에서 시스템 GND 기준으로 사용됨). 이 판단이 맞는지 검토.
 - 헤더 1개 vs 그룹별 2~3개 중 추천.
B15. 기타: 전원 표시 LED, 장착홀, 로고/버전 실크 지시사항.

## 통합 산출물
1. B11~B15 블록별: 부품표 / 핀-넷 연결표(모든 핀) / 설계 계산 / 레이아웃 노트 (Phase 2-1과 동일 형식)
2. F1~F3 수정 결과 (변경 전/후 표)
3. 보드 전체 연결 계약 JSON (Phase 2-1과 동일 스키마, B1~B15 전체, F1~F3 반영). HTML 안에 <script type="application/json" id="contract">로 포함. 리더가 다시 자동 검증한다.
4. 전체 BOM (FIT/DNP/VIRTUAL 구분, 단가 확인/미확인 구분, 합계와 100만원 예산 판정)
5. 전원 시퀀스 표: 단계 / 동작 / 확인 신호(PG) / 최소 대기시간 근거 (on/off 각각)
6. 펌웨어로 넘길 하드웨어 정의서: 핀맵, I2C 주소, INA228 레지스터 초기값(Phase 2-1 L1 포함), 타이머 캡처 설정
7. ERC 대비 목록 갱신, 리스크/질문 목록 갱신
