[승인된 설계 기준]
- 총 전류 측정 12채널. 전압 종류별 LDO 유지, 같은 전원에서 분기해 개별 측정.
- VDDI: U520 하나에서 VDDI_LPDP / VDDI_OSC / VDDI 분기.
  R525 DNP / R526 FIT. 피드백 자체 제거가 아니라 션트 전단 공통점 기준 FB.
- AVDDH2: MOSCATO 공통 출력에서 S/O 합산 1채널 + GM 1채널.
  S와 O를 다시 별도 측정하는 3채널 구조로 되돌리지 않는다.
- VGH1/2, VGL1/2: 각 공통 MOSCATO 출력에서 2분기, 분기별 측정.
- VGL 두 측정기는 공통 소스 기준 GND_F 및 기존 절연 전원/I2C 도메인 공유.
  GND_F를 시스템 GND나 각 션트 DUT 후단과 임의로 합치지 않는다.
- VDDIO1V2 1.2V / SYS_1V8 1.8V: U600/U620 기존 비측정 전원 유지.
  SYS_1V8은 DUT·MOSCATO·레벨시프터 공유 허용.
- 같은 공급원 그룹은 동시 ON/OFF. 전체 DDI/MOSCATO 순서를 무조건 동시로 바꾸는 승인이 아니다.
- 채널당 고정 션트 1개. 자동 range나 듀얼 션트 추가는 승인되지 않았다.
- 5uA ±0.5% 목표는 저전류 채널에 선택 적용(B안).
  전체 12채널에 일괄 보증하지 않는다. 채널별 확정 적용 범위/실측 하한은 미완료.
- 1Hz 저평균전류는 긴 blank와 소비회로 OFF/극저전류에 기인한다.
  '평균이 작다'를 '순간 피크가 작다'로 해석하지 않는다. 평균전류만 측정하고 파형 출력은 요구하지 않는다.

[다음 작업: 실제 R2 KiCad 검증]
1. 로컬 파일/터미널 접근 가능 여부와 실제 kicad-cli 경로·버전을 확인한다.
   데스크톱 앱을 사용한다는 이유만으로 로컬 실행 연결을 가정하지 않는다.
   이전 R1 검증 기준은 KiCad 8.0.9. 다른 버전이면 명시하고 결과를 구분한다.
2. SOURCE_MANIFEST.json과 대조해 입력을 고정한다. 사용자 로컬 수정이 있으면 덮어쓰지 않는다.
3. R2 실제 .kicad_sch로 새 netlist와 ERC를 생성한다. 이전 R1 결과는 재사용하지 않는다.
4. 아래 두 기존 검사 스크립트로 새 결과와 R2 계약/BOM/펌웨어 정의를 대조한다.
   tools/verify_r2.py
   tools/verify_r2_directory.py
   두 스크립트는 인수 단계에서 수정하지 않았고, 원격 Git Blob과 일치한다.
   KiCad 8.0.9 기준이고 Windows에서의 실제 실행은 아직 확인하지 않았다.
   Python 및 KiCad CLI의 실제 접근성과 라이브러리 설정부터 확인한다.
5. B8_VGL2 신규 시트의 핀 라벨 연결, 전체 계층 인스턴스, NC, Kelvin copper bridge,
   I2C 주소 스트랩, U520 FB 전환과 DUT 헤더 분기 연결을 새 netlist에서 우선 대조한다.
6. 불일치는 Ref.pin/net·기존값·실제값으로 기록한다. 오류/경고를 숨기지 않는다.
   이전 승인 범위를 넘어서는 전원/션트/제어 구조 변경은 별도 컨펌 대상이다.
7. 결과/작업 복사본은 원본 프로젝트 바깥의 새 폴더에 보관한다.
   기존 증거를 덮어쓰거나 같은 실패를 원인 해결 없이 반복하지 않는다.

기존 디렉터리 검사기 실행 형식(저장소 최상위 기준, Python/KiCad CLI가 접근 가능할 때):
